# Bullet bank

True alternative bullets, sections and skill groupings that aren't in the master CV.
When tailoring, `/apply` draws from these before writing anything new. Add good new
bullets here as they come up, ideally tagged with the application they came from so
you can see what worked where.

Everything here must be true. If it's not something you'd happily defend in an
interview, it doesn't belong here.

## Skills

Everything you've used, with how deeply where it isn't obvious. Only skills with real
use behind them can support a bullet; the rest are skills-line only.

- *Example:* **Languages**: Python (professional, 3 years), TypeScript (professional), Java (university only)
- *Example:* **Tools**: Terraform (professional, staging infrastructure only), Docker

## Confirmed facts

Facts that are true but don't appear in the master CV (tools you've used, context about
a role, things you did that didn't make the cut). `/apply` adds to this list when you
confirm something during tailoring.

- *Example:* Used Terraform to manage staging infrastructure at Example Corp (skills line only)
- *Example:* Mentored two junior developers at Example Corp
